# Azure Cognitive Search Demo

Este projeto demonstra como utilizar a Pesquisa Cognitiva do Azure para indexar, analisar e buscar informações em documentos com suporte de IA.

## 🧠 Funcionalidades exploradas

- Criação de serviço Azure AI Search
- Indexação de documentos
- Análise com Skillset (extração de frases-chave, PII etc)
- Consulta inteligente usando o Search Explorer

## 📁 Estrutura do Projeto

- **inputs/**: contém os documentos utilizados na indexação
- **insights/**: prints das etapas e resultados

## 💡 Aprendizados

- Como o Azure usa IA para transformar texto não estruturado em dados pesquisáveis
- Possibilidades com integração de pesquisa em apps e sites
- A importância do skillset para enriquecer a análise
